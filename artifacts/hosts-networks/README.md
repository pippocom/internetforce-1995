# Host e reti

> **Internet Force 1995–1996 Historical Archive**
> Ricostruzione e documentazione tecnica basate sui materiali originali Internet Force conservati da Marco Iannacone.
> Autore e curatore dell'archivio: Marco Iannacone · https://pippo.com
> Licenza: [CC BY 4.0](../../LICENSE)

Le tabelle `/etc/hosts`, `/etc/networks` e `/etc/netmasks` del firewall e di
DATA, come recuperate. Sono tra le migliori fonti singole per l'indirizzamento
del periodo.

| File | Host |
|---|---|
| `hosts.data`, `networks.data`, `netmasks.data` | DATA (206.20.95.3) |
| `hosts.firewall`, `networks.firewall`, `netmasks.firewall` | FIREWALL (206.20.95.129) |

I file sono **ORIGINALI SANITIZZATI**;
Registrano gli indirizzi degli host centrali, le macchine dell'ufficio, i nomi
di rete (`intfnet`, `intf-office`, `intf-world`, `intf-servers`) e le reti
dial-up dei POP, incluse le aggiunte del 1996.

I nomi host dell'ufficio compaiono come identificatori tecnici. I nomi personali
sono mantenuti solo come nome/handle.

Vedi [Panoramica dell'architettura](../../docs/01-architecture.md) e
[La LAN dell'ufficio](../../systems/office-lan/README.md).
