# Tools and utilities

> **Internet Force 1995–1996 Historical Archive**
> Historical reconstruction and technical documentation based on original Internet Force materials preserved by Marco Iannacone.
> Author and archive curator: Marco Iannacone · https://pippo.com
> License: [CC BY 4.0](../../LICENSE)

Software of the period that Internet Force used and that had been installed by Marco, kept for
provenance. The material retained here is included and published as part of
this project; provenance and attribution are given in the table.

| File | Origin | Purpose |
|---|---|---|
| `makezones-0.10` | University of Cambridge (Philip Hazel) | Generate forward/reverse DNS zones and bump SOA serials. |
| `digest.shar` | Brent Chapman | Majordomo digest and mail-utility shell archive. |
| `addr_stats.shar` | Brent Chapman | Mailing-list address statistics by domain. |
| `NCSA-HTTP-HOWTO.txt` | — | Local notes on building/using NCSA HTTPd. |
| `hypermail-HOWTO.txt` | — | Web archiving of mailing lists with Hypermail. |
| `swish-wwwwais-HOWTO.txt` | — | Search indexing notes (SWISH/WAIS). |

The `makezones` tool is also kept alongside the DNS material in
[`systems/data/dns/`](../../systems/data/dns/README.en.md) because it is part of
the zone-generation workflow.

See [Software inventory](../../docs/11-software-inventory.en.md).
