# Mappa tkined

> **Internet Force 1995–1996 Historical Archive**
> Ricostruzione e documentazione tecnica basate sui materiali originali Internet Force conservati da Marco Iannacone.
> Autore e curatore dell'archivio: Marco Iannacone · https://pippo.com
> Licenza: [CC BY 4.0](../../LICENSE)

`intf.snmp.map` è la mappa originale per il programma Scotty/Tkined (versione 1.3.4) della rete
Internet Force, creata dalla workstation Linux/X di Marco.

È un file **ORIGINALE**: non contiene credenziali né dati personali. È la fonte
primaria per la disposizione del monitoraggio descritta in
[Monitoraggio](../../docs/08-monitoring.md), e registra i dispositivi gestiti
(World Hub, hub dell'ufficio, il 2501 centrale, i router e gli access server dei
POP, DATA, USERS, DVLP e marco), gli obiettivi SNMP e gli stripchart di carico
interfaccia. Il formato del file tkined è simile a Tcl ma non è pensato per
essere modificato a mano.
