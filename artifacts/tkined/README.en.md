# tkined map

> **Internet Force 1995–1996 Historical Archive**
> Historical reconstruction and technical documentation based on original Internet Force materials preserved by Marco Iannacone.
> Author and archive curator: Marco Iannacone · https://pippo.com
> License: [CC BY 4.0](../../LICENSE)

`intf.snmp.map` is the original Scotty/Tkined (version 1.3.4) network map for the
Internet Force network, created from Marco's Linux/X workstation.

It is an **ORIGINAL** file: it contains no credentials or personal data. It
is the primary source for the monitoring layout described in
[the monitoring documentation](../../docs/08-monitoring.en.md), and it records
the managed devices (World Hub, office hub, the central 2501, the POP
routers and access servers, DATA, USERS, DVLP and marco), the SNMP targets
and the interface-load stripcharts. The tkined file format is Tcl-like but
is not meant to be edited by hand.
