# Customer-scale data

> **Internet Force 1995–1996 Historical Archive**
> Historical reconstruction and technical documentation based on original Internet Force materials preserved by Marco Iannacone.
> Author and archive curator: Marco Iannacone · https://pippo.com
> License: [CC BY 4.0](../../LICENSE)

`galactica-users-anonymized.txt` is an **ANONYMIZED** copy of a recovered
subscriber list from **galactica.it**, a Milanese provider of the period.
The list was obtained during a consultancy by Marco external to Internet Force
and is kept as a scale comparison with Internet Force's own customer base.

All names and aliases have been removed; only the row number and the
online-minutes column are preserved, which is what makes the file
interesting as a measure of size and usage for a comparable provider. The
file is included to give a concrete sense of scale, not to identify anyone.
