# Welcome Kit source

> **Internet Force 1995--1996 Historical Archive**\
> Author and archive curator: **Marco Iannacone** · https://pippo.com\
> Project license: [CC BY 4.0](../../../LICENSE), with the Welcome Kit
> exception stated in the license.

This directory preserves the source code and development material of the
**Internet Force Welcome Kit**.

The Welcome Kit was developed by **Marco Iannacone** for Internet Force as an
**additional consultancy activity** alongside his ordinary role as
system/network administrator. Before that project he had not used **Visual
Basic**: he learned it specifically to build it.

## Contents

- the Visual Basic source of **Easy!** and of the installation program
  (`.FRM`, `.FRX`, `.BAS`, `.MAK`);
- WinHelp help files and project documentation;
- bitmaps, icons and graphic resources;
- material related to building the installers and the multi-disk distribution;
- earlier versions collected in `OLD_VER2/`, with the `PRG-INST/`, `PROG-VB3/`,
  `PROG-VB4/` and `PROG-VB4.32/` folders.

These files give a concrete view of how a small Windows/Visual Basic
application was developed and distributed in the 1990s.

## Note

Not all the material preserved here is Internet Force's own: the
`OLD_VER2/FILES/` and `OLD_VER2/ZIP-FILE/` collections contain third-party
client packages of the period, used to prepare the Welcome Kit, which keep
their original licenses.
