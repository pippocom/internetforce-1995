# it.comp.linux — Linux FAQ

> **Internet Force 1995–1996 Historical Archive**
> Historical reconstruction and technical documentation based on original Internet Force materials preserved by Marco Iannacone.
> Author and archive curator: Marco Iannacone · https://pippo.com
> License: [CC BY 4.0](../../../LICENSE)

This directory preserves material from the **`it.comp.linux` FAQ** maintained by
Marco Iannacone.

## File

[`linux-faq-1-of-3.txt`](linux-faq-1-of-3.txt)

The file is only the **first of the three parts** in which that version of the
FAQ was published. Parts **2/3** and **3/3** have not yet been recovered: this is
**not an accidentally truncated file**, but one part of a larger document.

The index of the complete FAQ covered sections up to **15**, plus a glossary and
acknowledgements; the preserved fragment reaches only the part about Linux/HOWTO
documentation.

## A later version

A complete copy of a later version of the FAQ is still available in the
historical Usenet archive maintained by **Vittorio Bertola**:

<https://bertola.eu/usenet/faq/testi/linux.txt>

It is not necessarily the same fragmentary version preserved here.

## History of the FAQ

Marco maintained the `it.comp.linux` FAQ up to version **0.9e**. He then handed
the FAQ over to the newsgroup and the community, and moved his own work towards a
document more oriented to decision-makers and to the organisational adoption of
Linux, the **“Linux Guide for Managers”**, still available at:

<https://www.pippo.com/mirrors/linuxguide.html>

This development was consistent with a direction already present in the Linux
FAQ, which went beyond the technical use of the system and also addressed the
introduction of Linux in companies.
