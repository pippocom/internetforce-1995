Questa cartella raccoglie testi Usenet che non è stato possibile attribuire con
certezza a un newsgroup o a una data.

## File

### [`cyberspazio.txt`](cyberspazio.txt)

Testo di **Marco Iannacone** tratto dalla **Guida ad Internet e alla Realtà
Virtuale**. La copia recuperata non conserva un header Usenet sufficiente a
stabilire con certezza il newsgroup e la data di pubblicazione; per questo è
conservata qui invece di essere attribuita arbitrariamente a uno specifico
newsgroup.
