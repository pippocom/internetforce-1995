# Listino Aziende Internet Force — 15 giugno 1996

> Documento originale Internet Force del 1996, conservato e fornito nel 2026 da **Pascal Schait**, socio fondatore di Internet Force.

Questa cartella conserva il **Listino Aziende** di Internet Force datato **15 giugno 1996**. Il documento mostra che l'offerta commerciale del provider non si limitava all'accesso dial-up individuale, ma comprendeva servizi per aziende: indirizzi IP statici, collegamento di LAN, linee dedicate, registrazione di domini, DNS, realizzazione di pagine Web e hosting.

## Cosa documenta

Il listino comprende, fra l'altro:

- **IP Address Statico**, con routing sulla rete Internet Force;
- **LAN IP Dial-Up** per 4, 8 o un numero illimitato di PC;
- collegamenti **LAN IP 19,2 Kbps** e **64 Kbps**;
- registrazione del **Domain Name** e backup del Domain Name Server;
- realizzazione e manutenzione di pagine HTML;
- spazio Web sui server Internet Force;
- assistenza tecnica specializzata.

I prezzi sono espressi in **lire italiane** e, salvo le voci indicate come una tantum, sono annuali. Il documento indica inoltre IVA al 19% e tempi di attivazione nell'ordine di 15–20 giorni lavorativi per diversi servizi di connettività.

Alcuni esempi rendono concreta la scala commerciale dell'epoca:

| Servizio | Prezzo indicato |
|---|---:|
| IP statico | Lit. 500.000 attivazione + Lit. 1.600.000/anno |
| LAN IP Dial-Up, 4 PC | Lit. 2.000.000/anno |
| LAN IP Dial-Up, 8 PC | Lit. 3.500.000/anno |
| LAN IP Dial-Up, illimitata | Lit. 5.000.000/anno |
| LAN IP 19,2 Kbps | Lit. 1.500.000 attivazione + Lit. 10.000.000/anno |
| LAN IP 64 Kbps | Lit. 1.500.000 attivazione + Lit. 21.000.000/anno |
| Realizzazione pagine HTML | Lit. 150.000/ora; Lit. 500.000/4h; Lit. 800.000/8h |
| Registrazione Domain Name | Lit. 500.000 una tantum |
| Backup Domain Name Server | Lit. 500.000/anno |
| Spazio Web 1 / 5 / 10 MB | Lit. 1.000.000 / 4.000.000 / 6.000.000 all'anno |

## Quanto era grande un sito Web aziendale nel 1996?

Il listino proponeva spazio Web in tagli da **1 MB, 5 MB e 10 MB**; oltre 10 MB il prezzo era **a preventivo**. Nel 1996 queste dimensioni erano coerenti con il Web aziendale dell'epoca: per molte piccole imprese la presenza online poteva consistere in alcune pagine di presentazione, recapiti e form di contatto, eventualmente accompagnati da un piccolo catalogo prodotti.

La dimensione dei siti era legata anche alla rete dei visitatori. Molti utenti si collegavano tramite modem a **28,8 kbit/s**: pagine ricche di immagini ad alta qualità avrebbero richiesto tempi di trasferimento molto lunghi. Spazio server e banda disponibile spingevano quindi verso siti piccoli, leggeri e prevalentemente testuali rispetto agli standard contemporanei.

Un dettaglio rende bene la scala: **10 MB era già il taglio più grande con un prezzo pubblicato nel listino; oltre, si passava al preventivo**.
