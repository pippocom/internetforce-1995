# MaISoft Hypertxt — Historical Source Archive

### What's in this archive

This directory contains the surviving original source files of MaISoft Hypertxt / Guida ad Internet e alla Realtà Virtuale, a hypertext guide created by Marco Iannacone in the 1990s for Microsoft Windows using WinHelp.

The HYPERTXT/ folder preserves the original directory structure and filenames, including WinHelp project files (.HPJ), text and markup files (.RTF), images, icons, documentation, scripts, and supporting materials.

It also includes distribution files and reference materials used during development.

This is a historical snapshot, not a modern, ready-to-build project. WinHelp is no longer supported by modern operating systems. The short, uppercase filenames reflect the DOS 8.3 naming convention, which also made it possible to share the files on floppy disks. Unfortunately, one of the original source files, GERGO_1.RTF, is missing.

All files are preserved in their original form, without modifications. They offer a glimpse into how a Windows hypertext guide was developed in the 1990s, including the original .BAT script showing the commands used to build it.

### The 2026 Web Edition

In 2026, Marco reconstructed the guide as an HTML website, with the assistance of AI tools. The reconstruction combines the recovered original sources (dating up to version 1.30d) with content extracted by decompiling the WinHelp files from version 1.44.

The HTML edition can be explored at https://pippo.com/hypertxt/.
