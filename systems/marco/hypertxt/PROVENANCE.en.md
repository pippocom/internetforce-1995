# Hypertxt source provenance

> **Internet Force 1995–1996 Historical Archive**\
> Historical reconstruction and technical documentation based on original Internet Force materials preserved by Marco Iannacone.\
> Author and archive curator: **Marco Iannacone** · https://pippo.com
> License: [CC BY 4.0](../../../LICENSE)


The Hypertxt files recovered in this repository **are not the complete original development archive** of the guide.

Hypertxt was developed on the author’s personal PC, with **Windows in a dual-boot configuration**. The complete project archive lived on the Windows partition, also because the compilers required to build the WinHelp files operated in that environment at the time.

That primary archive was lost over the years.

What survived was a partial copy stored on the Linux workstation **`marco`**, consisting of snapshots transferred occasionally and without a regular archival schedule. The recovered sources therefore represent only part of the original development environment.

This provenance explains, among other things:

- files from different versions existing side by side;
- version metadata that is not always synchronized;
- sources surviving for some components but not others;
- binaries from later releases without their complete matching sources;
- the absence of published releases.

The Linux copy survived because it was included on the `marco` workstation DAT cassette recovered in 2026. See [Archive provenance](../../../docs/archive-provenance.en.md).

The absence of a release or source file from this copy therefore **does not imply that it never existed** in the primary project archive.
