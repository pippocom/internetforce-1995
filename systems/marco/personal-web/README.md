# Archivi Web personali

> **Internet Force 1995–1996 Historical Archive**\
> Ricostruzione e documentazione tecnica basate sui materiali originali Internet Force conservati da Marco Iannacone.\
> Autore e curatore dell’archivio: **Marco Iannacone** · https://pippo.com
> Licenza: [CC BY 4.0](../../../LICENSE)

Questa directory raccoglie snapshot storici di siti personali collegati all’infrastruttura Internet Force.

Sono conservati come **artefatti Web**, non dentro un singolo sistema, perché possono documentare contemporaneamente contenuti personali, virtual hosting, home Unix, CGI e servizi distribuiti su più host.

## Snapshot disponibili

- [`pippo.com-1997/`](pippo.com-1997/) — copia Web del 1997 della home personale di Marco Iannacone, recuperata dalla Wayback Machine. Il sito conserva tecniche tipiche del Web 1995–1997 e collegamenti diretti ai servizi Internet Force.

Lo snapshot contiene anche la pagina Web e i pacchetti scaricabili di
**Hypertxt**; il materiale Hypertxt e la sua provenienza sono indicizzati in
[`../hypertxt/README.md`](../hypertxt/README.md).
