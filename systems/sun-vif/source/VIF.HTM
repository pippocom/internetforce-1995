VIF (Virtual Interface) for SunOS 4.x.

This distribution is slightly remastered VIF version 1.01 floating around the net (see if_vif.c for credits). Note that the original distribution also includes HP-UX 9.x port.

  • download if_vif.c (just click it and when you have it in your Web browser window save it through the File menu);
  • compile loadable module as following: 
    cc -O -DDETACH -DKERNEL -DINET -D`arch -k` -c if_vif.c
ld -o vif.o -r if_vif.o
  • download vif.rc script and modify it according to your needs;
  • install vif.o and vif.rc some place, e.g.: 
    install -m 0755 vif.o vif.rc /etc
  • update /etc/rc.local and make it calling vif.rc, e.g: 
    echo /etc/vif.rc >> /etc/rc.local
  • reboot or simply run vif.rc and don't forget to have fun :-)
