This is a **SANITIZED ORIGINAL**. USERS was the primary mail host for
`internetforce.com` (MX 0) and ran Sendmail 8.6.12. The POP3 and IMAP
services were started from `inetd` (see
[`../system/`](../system/README.en.md)). See [Email](../../../docs/04-email.en.md).
