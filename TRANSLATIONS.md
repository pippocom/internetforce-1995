Questo repository è bilingue. La convenzione è: **il nome base è in italiano**, la versione inglese ha il suffisso `.en` (es. `README.md` italiano, `README.en.md` inglese). Vale anche per i documenti in `.txt` (es. `domini_com_net.txt` / `domini_com_net.en.txt`). Le configurazioni e gli artefatti non hanno lingua e restano in un'unica copia canonica.

## Sito statico

Le pagine del sito seguono la stessa convenzione: versione italiana senza suffisso, versione inglese `.en.html` (per esempio `site/index.html` / `site/index.en.html`, `site/pop-map.html` / `site/pop-map.en.html`, e le schede in `site/systems/`).

## Note

- Tutti i documenti narrativi e i README delle aree `docs/`, `systems/` e `artifacts/`, più il `README` di radice, sono bilingui secondo la convenzione sopra.
- I file di configurazione e gli artefatti (`systems/**/*.cfg`, `artifacts/**`, zone DNS, immagini disco, PDF) sono neutri rispetto alla lingua: nessuna traduzione, una sola copia canonica.
- Documenti moderni intenzionalmente monolingua: `docs/09-historical-notes.VIF-NETWORK-EVOLUTION.md` (approfondimento storico VIF). Le licenze di terze parti (per esempio `site/assets/vendor/marked.LICENSE.md`) restano nella loro lingua originale.
- Durante la transizione i link dai file già tradotti puntano ai nomi base; i file inglesi usano il suffisso `.en.md`.
- In un passaggio precedente sono stati consolidati nei documenti canonici i file temporanei `docs/*.NARRATIVE.md`, `docs/*.TECHNICAL-ADDENDUM.md` e le bozze `docs/03-cisco-routing-and-access.*`, `docs/04-sunos-primer.*`, `docs/05-dns-and-domains.*`, `docs/16-monitoring-and-observability.*`, che non fanno più parte del repository.
