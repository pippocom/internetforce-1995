This repository is bilingual. The convention is: **the base name is in Italian**, the English version carries the `.en` suffix (e.g. `README.md` Italian, `README.en.md` English). The same applies to the `.txt` documents (e.g. `domini_com_net.txt` / `domini_com_net.en.txt`). Configurations and artifacts are language-neutral and keep a single canonical copy.

## Static site

The site pages follow the same convention: Italian version without suffix, English version `.en.html` (for example `site/index.html` / `site/index.en.html`, `site/pop-map.html` / `site/pop-map.en.html`, and the pages under `site/systems/`).

## Notes

- All narrative documents and area READMEs under `docs/`, `systems/` and `artifacts/`, plus the root `README`, are bilingual according to the convention above.
- Configuration and artifact files (`systems/**/*.cfg`, `artifacts/**`, DNS zones, disk images, PDFs) are language-neutral: no translation, one canonical copy.
- Intentionally single-language modern documents: `docs/09-historical-notes.VIF-NETWORK-EVOLUTION.md` (VIF historical deep-dive). Third-party licences (for example `site/assets/vendor/marked.LICENSE.md`) remain in their original language.
- During the transition, links from already-translated files point to base names; English files use the `.en.md` suffix.
- In an earlier pass the temporary `docs/*.NARRATIVE.md`, `docs/*.TECHNICAL-ADDENDUM.md` files and the drafts `docs/03-cisco-routing-and-access.*`, `docs/04-sunos-primer.*`, `docs/05-dns-and-domains.*`, `docs/16-monitoring-and-observability.*` were consolidated into the canonical documents and are no longer part of the repository.
